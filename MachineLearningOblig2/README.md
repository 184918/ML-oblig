# Oblig2: opptrening av ML-modell

I denne obligen skulle vi lage en modell og trene den opp. 
Vår modell er en enkel nettside koblet opp mot streamlit, som kategoriserer kundeanmeldelser enten som "positive" eller "negative".
Løsningen kan være gunstig når vi ikke har stjernerangering eller lignende. 

Modellen bruker logistisk regresjon samt TF-IDF fra scikit-learn.

# Datasett

Modellen har benyttet datasettet fra Amazon delen av UCI-datasettet Sentiment Labelled Sentences
https://archive.ics.uci.edu/dataset/331/sentiment+labelled+sentences
